# Mac 触控板手写笔记

**桌上放不下 iPad、或者懒得拿 iPad 的时候，拿起一支几块钱的电容笔，直接在 MacBook 触控板上写。**

[English](README.en.md)

![主窗口](docs/images/main-window.png)

整块触控板对应画布上的书写区域：笔尖碰到哪里，字就写在哪里。防误触会按触点形状分出笔尖、手指和手掌，写字时手腕可以放心搭在触控板上。

适合随手的简单书写：算一道题、画个草图、记几个关键词、给网页内容做个标注。它代替不了 iPad + Apple Pencil 的精细书写，胜在不用另外拿设备、不占桌面。

## 功能

- **在任何界面上记笔记**：按 **⌃⌥N**（Control + Option + N）呼出小窗，全屏的网页、视频、PPT 上也能用；再按一次收起，自动保存。小窗可以拖动、改大小，位置会记住。
- **防误触**：读取每个触点的形状（大小、长短轴），只让笔尖落笔；手掌和手指不会画出杂线。
- **两种落笔方式**：笔尖一接触就书写；或者"轻触只显示位置，按下才书写"，先看清笔尖对着哪里再写。
- **激光笔**：按住 ⌥（Option），笔尖处只显示一个红点、不出墨，方便看清笔到底在哪里；小窗里也能用。
- **工具**：钢笔、荧光笔、橡皮（局部擦 / 整笔擦）、套索（选中、移动、换色、删除）、直线、矩形、椭圆、箭头、文字；5 种颜色、3 种粗细。
- **笔记库**：左侧列表带缩略图、可搜索，自动保存；纸张可选空白、横线、方格、点阵。
- **导出**：矢量 PDF、PNG；图片可以拖进来或粘贴进来。
- **本地优先**：所有笔记只存在你自己的电脑上，不联网。

## 需要什么

- 搭载 Apple 芯片（M1 及更新）的 MacBook，macOS 13 及以上。不支持 Intel 芯片的 Mac。
- 一支**被动电容笔**：导电纤维头或透明圆盘头那种，不需要蓝牙、不用充电。笔头太粗可能被当成手指，可以在应用里调宽笔尖识别范围（见使用说明）。

## 安装

1. 在 [Releases](../../releases) 下载最新的 `.dmg`，把「Trackpad Studio 手写.app」拖进「应用程序」。
2. 第一次打开会提示"无法验证开发者"：本应用没有 Apple 付费签名，属于正常现象。先点"完成"，再打开「系统设置 → 隐私与安全性」，拉到最下方点"仍要打开"。
   不行的话，在终端运行下面这行命令，然后再打开：
   ```bash
   xattr -dr com.apple.quarantine "/Applications/Trackpad Studio 手写.app"
   ```
3. 授权**输入监控**（防误触和小窗书写要用）：「系统设置 → 隐私与安全性 → 输入监控」里打开它的开关，然后 ⌘Q 退出、重新打开。

完整说明见 [docs/使用说明.txt](docs/使用说明.txt)。

## 常用操作

| 操作 | 按键 |
|---|---|
| 在任何界面呼出 / 收起小窗 | ⌃⌥N |
| 书写模式 ⇄ 指针模式（点列表、拖窗口） | Esc |
| 激光笔：只显示笔尖位置，不出墨 | 按住 ⌥ |
| 钢笔 / 荧光笔 / 橡皮 / 套索 / 直线 / 矩形 / 椭圆 / 箭头 | 1 – 8 |
| 换颜色 / 换粗细 | C / W |
| 撤销 / 重做 | ⌘Z / ⇧⌘Z |
| 新建笔记 | ⌘N |
| 导出 PDF / PNG | ⌘E / ⇧⌘E |

## 让它适配你的手和笔

防误触的阈值是按作者的手和笔、用真实录制数据校准的。用 AI 编程助手（Claude Code、Codex、Cursor 等）打开这个仓库，告诉它哪里不顺手，比如"双指拖动经常识别不出来"。它会读 [AGENTS.md](AGENTS.md)，让你录几段触点数据，按数据调阈值并验证。`calibration/reference/` 是作者的录制，用来确认改动没有破坏原有场景。

## 已知限制

- 电容触控板感应不到悬空的笔尖，所以没有"悬停预览"；"轻触显示位置"模式是替代办法。
- 用到了 macOS 私有接口（MultitouchSupport 读触点形状，窗口服务器接口在别的应用前台时隐藏指针），所以不能上架 App Store，系统大版本更新后可能需要适配。
- 压力感应依赖触控板是否报告压力数据，需要在应用里校准一次。
