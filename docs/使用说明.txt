Trackpad Studio 手写版：用电容笔在 MacBook 触控板上写字

适用：搭载 Apple 芯片（M1 及更新）的 Mac，macOS 13 及以上；不支持 Intel 芯片的 Mac。需要被动电容笔（导电纤维头或透明圆盘头）。

一、安装
1. 把「Trackpad Studio 手写.app」拖进「Applications（应用程序）」文件夹。
2. 第一次打开会提示“无法验证开发者”。本应用没有 Apple 付费签名，属于正常现象。解决方法：
   · 先双击打开一次，出现提示后点“完成”；
   · 打开「系统设置 → 隐私与安全性」，拉到最下方，点“仍要打开”，输入开机密码确认。
   如果上面的方法不行，打开“终端”，粘贴下面这行命令并回车，然后再双击打开：
   xattr -dr com.apple.quarantine "/Applications/Trackpad Studio 手写.app"

二、授权“输入监控”（用于防误触，强烈建议开启）
防误触要读取每个触点的形状，才能区分笔尖、手指和手掌。
1. 打开「系统设置 → 隐私与安全性 → 输入监控」，打开「Trackpad Studio 手写」的开关。
2. 完全退出应用（⌘Q），再重新打开。
不授权也能写，但只能按位置猜哪个是笔，手掌放在触控板上时可能画出杂线。

三、使用
· 左边是笔记列表，右边是当前笔记。⌘N 新建笔记；笔记自动保存，不需要手动保存。
  在列表里双击标题可以改名，右键可复制或移到废纸篓（废纸篓里还能找回）。⌃⌘S 显示或隐藏列表。
· 打开后就是书写模式（状态栏左下角显示“书写”）。笔尖接触触控板即落笔，整个触控板对应画布中间的书写区域。
  书写模式下鼠标指针不动，所以笔记列表暂时不能点。按 Esc 切到“指针”模式，就能点列表和工具栏；点完工具会自动回到书写。
· 工具（按数字键切换）：1 钢笔、2 荧光笔、3 橡皮、4 套索、5 直线、6 矩形、7 椭圆、8 箭头；T 添加文字。
· C 换颜色（黑、蓝、红、绿、黄），W 换粗细。钢笔和荧光笔各自记住自己的颜色和粗细。
· 橡皮默认只擦掉笔经过的那一段笔迹；想一碰就擦掉整笔，在「工具」菜单打开“橡皮擦除整笔”。
· 套索：圈住笔迹即可选中，然后可以拖动、按 C 或点颜色换色、⌫ 删除、⌘C/⌘X/⌘V 拷贝剪切粘贴、⌘D 复制一份。
· 可以把图片拖进来，或从别的应用复制图片后 ⌘V 粘贴。
· 双指拖动平移，双指捏合缩放；⌘0 回到实际大小。⌘Z 撤销，⇧⌘Z 重做。
· 「显示 → 纸张」可选空白、横线、方格、点阵，每条笔记单独记住。
· ⌘E 导出 PDF（矢量，适合打印和放进其他笔记软件），⇧⌘E 导出 PNG 图片。
· 旧版本保存的 .trackpad.json 文件：「文件 → 导入笔迹文件」（⌘O）。
· 轻触定位、按下书写：在「工具」菜单选“轻触只显示位置，按下才书写”。笔尖轻轻碰触控板时，只出现一个蓝色小圈
  告诉你笔在哪里，不会写出字；按下触控板（听到“咔”的点按）才开始写，按住移动即可。
  想不用按到“咔”也能写：在「工具」菜单选“校准按压力度…”，按状态栏提示先轻碰并移动，抬笔后再用写字的力度
  按着移动。校准成功后，稍用力就能写，蓝色小圈上的弧线会显示离“开始书写”还差多少力度。觉得太重或太轻，
  书写时按 [（更轻）或 ]（更重）微调。如果提示“没有压力数据”，就只能用按下（点按）的方式。
· 激光笔：书写模式下按住 ⌥（Option），笔尖处出现一个红点，只显示笔在哪里，不会写出字；松开 ⌥ 后，
  抬一次笔再落下就恢复书写。小窗里也能用。
· 落笔位置预测（默认关闭）：手掌搭在触控板上时预测笔会落在哪里，误差约一个字，可在「显示」菜单打开。
· 小窗（在任何应用上面记笔记，包括全屏的视频、PPT、网页）：随时按 ⌃⌥N（Control+Option+N），当前笔记会以小窗
  出现在最前面，直接就能写；再按一次 ⌃⌥N 收起（自动保存）。拖动小窗顶部的标题栏可移动位置，拖边角可改大小，
  位置和大小会记住。屏幕顶部菜单栏的笔形图标也能打开小窗、新建笔记。点 Dock 图标或「显示 → 回到主窗口」回到完整界面。
  关掉主窗口后应用仍在后台运行，⌃⌥N 随时可用；彻底退出用菜单栏笔形图标里的“退出手写笔记”或 ⌘Q。
· 菜单「防误触」：可开关防误触、选择左手或右手书写、允许手指写字。

四、如果你的笔写不出来或时断时续
防误触的参数是按作者的笔校准的：只接受长轴 ≤ 8 mm 的小触点作为笔尖。你的笔头如果更粗，可以：
· 在画布中按 = 放宽笔尖上限（按 - 收紧），状态栏会提示新的上限。打开「显示 → 在状态栏显示调试信息」可以看到笔尖实时的长轴，方便对照调整；
· 或在「防误触」菜单关闭「按触点形状识别笔尖」。
手指能写而笔完全没反应，通常是这支笔和触控板不兼容，用力按也没用。

五、隐私
所有笔迹和设置只保存在你自己的电脑上，不联网。笔记存放在
~/Library/Application Support/TrackpadStudio-Handwriting/Notes/
（「文件 → 在访达中显示笔记文件夹」可直接打开，备份这个文件夹即可）。
菜单里的“录制触点数据”只在你主动点击时录制，保存在
~/Library/Application Support/TrackpadStudio-Handwriting/touchlog/

六、卸载
退出应用后，把它从「应用程序」拖到废纸篓。
